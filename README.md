# Projet PRWB 2526 - Groupe c06 - EPayFC

Plateforme web d'achat et de vente développée dans le cadre de mon Bachelier en Informatique de gestion à l'EPFC.

## Présentation

EPayFC est une plateforme de vente en ligne permettant aux utilisateurs de publier des articles, consulter les ventes disponibles et effectuer des achats ou des enchères.

Le projet a été réalisé en groupe dans le cadre du cours de Projet Web à l'EPFC.

J'ai participé au développement de différentes fonctionnalités de l'application, avec un intérêt particulier pour la logique backend en PHP.

## Fonctionnalités principales

- Création de compte et authentification
- Consultation des articles mis en vente
- Mode Guest en lecture seule
- Création et modification d'annonces
- Gestion des images des articles
- Achat direct
- Système d'enchères
- Consultation et suivi des achats et des ventes
- Gestion du profil utilisateur et modification du mot de passe
- Gestion des catégories

## Technologies utilisées

- PHP
- JavaScript
- AJAX
- jQuery
- HTML
- CSS
- MySQL

## Architecture

L'application est organisée selon une architecture MVC avec séparation entre les modèles, les vues et les contrôleurs.
